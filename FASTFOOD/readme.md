
FastBite 🍟
FastBite is a beginner's venture into software development, crafted using C# WPF within the Visual Studio environment. It relies on MySQL server integration for its functionality.

This project serves as an initial foray into learning a new programming language.

Introduction to FastBite
FastBite represents a unique approach to a Point of Sale (POS) system, also referred to as TPV in Spanish, specifically designed for restaurant use.

Features of FastBite
FastBite offers a range of capabilities, including table management within your restaurant. It enables users to modify table statuses, initiate orders, and select specific items for each order.
